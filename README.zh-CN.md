# SixDots

[English](README.md) · [简体中文](README.zh-CN.md)

**用行首六点手柄，顺手整理笔记。**

SixDots 为 Obsidian 带来 Notion 式块操作：拖动整段文字、连同子项一起调整列表顺序，或从正文旁的小菜单中快速转换格式。

## 可以做什么

- **拖拽排序。** 在同一笔记中移动段落、单个标题、引用、Callout 和围栏代码块。
- **保留列表层级。** 调整同组兄弟项的顺序，子内容一起移动；有序列表保留起始编号。
- **就地转换格式。** 将支持的文本转为标题、无序列表、待办、引用或 Callout。
- **复制块链接。** 复用当前块的原生 ID，或在明确操作后为它创建 ID。
- **提取到新笔记。** 将符合条件的段落或列表项子树提取为独立笔记，源位置保留链接。
- **键盘操作。** 从命令面板打开块菜单或执行常用动作，自行设置快捷键。

## 如何使用

1. 在 **实时预览** 或 **源码模式** 中打开 Markdown 笔记。
2. 桌面端将指针悬停在支持的内容块旁；手机和平板轻点正文放置光标，手柄会跟随当前块。
3. **单击或轻点**手柄打开菜单。鼠标可直接拖拽；触屏需先长按手柄约 **350 毫秒**，再拖动排序。

自动折行的段落仍是一个块；父列表项包含其子内容。插入线表示允许的落点，按 **Esc** 可取消拖拽。移动和格式转换均可正常撤销。

使用键盘时，在命令面板搜索 **SixDots：打开块操作**。也可直接执行向上／向下移动、转为待办、转为标注、复制块链接和提取到新笔记。插件不预设快捷键。

## 安装

SixDots **尚未上架 Obsidian 社区插件市场**，可从 GitHub Releases 手动安装。

手动安装已发布版本：

1. 从 [Releases](https://github.com/saltcoffee/six-dots/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`，或解压发布包中的 `six-dots` 目录。
2. 将这三个文件放入 `<你的笔记库>/.obsidian/plugins/six-dots/`。
3. 重启 Obsidian，在 **设置 → 第三方插件** 中启用 **SixDots**。

需要 Obsidian **1.8.7 或更高版本**，支持桌面、手机和平板的编辑视图。插件使用 1.8.7 的 API 编译检查，应用内实测使用 Obsidian 1.14.5。移动端支持目前为早期预览，已通过触摸事件自动化测试和 Obsidian 手机模式验证，iOS／Android 真机验证尚待完成。桌面端已在 macOS 中实测，Windows 和 Linux 尚待验证；不支持阅读视图。

手机上可正常在正文滚动和选词，排序时从手柄长按后发起；过早移动会取消本次手势。也可以直接选择菜单中的**向上／向下移动块**，无需拖拽。移动端始终使用跟随光标的手柄，即使同步了桌面端的悬停设置。如果自动复制失败，对话框会保留块链接，可选中文字手动复制。

## 设置

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 启用拖拽排序 | 开启 | 关闭拖拽后，仍可使用菜单和命令。 |
| 手柄显示方式 | 桌面端悬停，移动端跟随光标 | 桌面可切换；手机和平板始终跟随光标。 |
| 默认标注类型 | 笔记 | 可选笔记、信息、提示和警告。 |
| 提取目录 | 与源笔记同目录 | 可填写库内已有目录，`/` 表示笔记库根目录。 |

Obsidian 设置为中文时，插件显示中文；其他所有语言统一显示英文。

## 使用边界

- 列表拖拽仅限同组兄弟项，不会改变缩进层级，也不支持跨笔记拖拽。
- 移动标题只移动标题这一行；请先展开已折叠的标题。
- 可用格式取决于块类型。转为标题仅支持单源文本行；以文本开头的列表项可在普通无序项与标准待办间切换。以代码、引用或标题开头的列表项不提供格式转换或新增块 ID。
- 同一源文本行包含多层标记的紧凑嵌套列表（如 `- - 子项`）受到保护，不提供局部块操作。
- 表格、数学块、frontmatter、注释及不支持的结构受到保护，不能从中拖出局部内容。
- 悬停、菜单和拖拽预览不会修改笔记；格式转换会写入对应的原生 Markdown。
- **创建块链接会添加原生 `^block-id`。** 复制结果固定为含库内完整路径的 Wikilink，不跟随通常的 Markdown 链接偏好，仅用于当前笔记库。撤销新创建的 ID 后，已复制的链接会失效。
- 当前版本不转换或提取含有 ID 的内容。含标题的子树，以及无法安全迁移依赖的内容，也不能提取。
- **撤销提取只恢复源文本，新笔记会保留。** 提取部分完成时，请先核对两份笔记再重试；插件不会自动删除其中任何一份。
- Callout、Wikilink 和块引用属于 Obsidian 语法，在其他 Markdown 应用中可能无法正常使用。

## 隐私

SixDots 在本地运行，无需账号，不发起网络请求，不收集遥测数据，不访问笔记库之外的文件。设置保存在插件配置中，只有主动选择复制操作时才写入剪贴板。
